5. SYMBOLS.JSON — 99-ENTRY BIDIRECTIONAL LEXICON
-------------------------------------------------
Single source of truth for math/science symbols across the whole team.

Each entry structure:
  {
    "name":    "membership",
    "latex":   "\\in",
    "aliases": ["is in", "belongs to", "is an element of", ...],
    "tts": {
      "casual":      "in",
      "normal":      "is an element of",
      "pedagogical": "is an element of"
    },
    "domain": "set_theory"
  }

Coverage:
  Arithmetic     : + - x / = != ~= < > <= >= +- ! % = |
  Roots          : sqrt, cbrt, 4th root
  Set Theory     : empty set, membership, subsets, supersets, union,
                   intersection, set difference, symmetric diff, disjoint union,
                   N Z Q R C
  Logic          : AND, OR, NOT, implies, iff, for all, there exists,
                   therefore, because
  Calculus       : integral, double/triple/contour integral, partial,
                   nabla, summation, product, infinity
  Geometry       : angle, parallel, perpendicular, degree, congruent, similar
  Linear Algebra : dot product, tensor product, norm
  Greek lower    : full alphabet (alpha through omega)
  Greek upper    : Gamma, Delta, Lambda, Pi, Sigma, Omega
  Number sets    : N Z Q R C

Special features:
- x (times) is context-dependent:
    arithmetic    -> "times"
    set theory    -> "Cartesian product"
    linear algebra-> "cross product"
- subset symbol has ambiguity flag (means both subset and proper subset)
- Three TTS modes per symbol: casual, normal, pedagogical


6. SPEECH_NORMALIZER.PY — SPOKEN MATH TO UNICODE (Chai's module)
-----------------------------------------------------------------
Converts Deepgram transcript -> structured Unicode math for the LLM.

Examples:
  "what is the square root of x"          -> "what is sqrt(x)"
  "x belongs to A union B"                -> "x in A union B"
  "A is a proper subset of B"             -> "A is a proper subset of B"
  "the integral from a to b of f dx"      -> "int_a^b f dx"
  "the sum from i equals 1 to infinity of"-> "sum_{i=1}^{inf}"

Architecture:
- Loads all mappings from symbols.json — no hardcoded symbol lists
- Domain auto-detection (arithmetic vs set theory)
- Handles: derivatives, integrals with bounds, limits, summations,
  partial derivatives, set-builder notation
- Context-aware multiplication sign
- Pre-substitution pass for tokens needed by structured patterns

Tests: 21/21 passing


7. MATH_RENDERER.PY — UNICODE MATH TO SPEAKABLE ENGLISH (Kyle's module)
------------------------------------------------------------------------
Reverse of the normalizer — converts LLM output to TTS-safe English.

Examples:
  "sqrt(x) + x^2"   -> "square root of x plus x squared"
  "x in A union B"  -> "x is an element of A union B"
  "\frac{dy}{dx}"   -> "the fraction dy over dx"

Features:
- Strips LaTeX delimiters ($...$, \[...\])
- Handles LaTeX commands (\frac, \sqrt, \int)
- Symbol -> spoken from symbols.json
- Matrix pronunciation
- Structured notation: derivatives, integrals, limits, scientific notation
- Cleans markdown artifacts (*, _, `)

Tests: 8/8 passing

10. AGENT.PY — LLM BRAIN (Andy's module, extended)
---------------------------------------------------
Andy's original: single-turn, OpenAI Responses API, gpt-5-codex, no history.

Extended with:
- Multi-turn conversation history
- Three modes:
    walkthrough  — Socratic, guides step by step, never gives answer
    teach_back   — student teaches agent, agent asks concept-checks,
                   can pretend to misunderstand poor explanations
    quiz         — agent explains with one deliberate mistake,
                   student must find it
- Mood-aware prompting:
    frustrated  -> warm, slow down, simplify
    confused    -> different angle, simple analogy
    disengaged  -> fun fact, surprising angle
    confident   -> push harder, next concept
    neutral     -> normal tone
- detect_mode() — switches mode on voice wake phrases:
    "quiz mode" / "quiz me"      -> quiz
    "teach back" / "let me explain" -> teach_back
    "help me" / "walk me through"   -> walkthrough
- max_output_tokens=150 — keeps responses short for voice
- Terminal test harness (python agent.py)


11. MAIN.PY — THE FULL PRODUCT
-------------------------------
Wires everything into a working voice conversation loop:

  Mic
   -> RealtimeSTT (faster-whisper, local)
     -> speech_normalizer.normalize()
       -> agent.respond()  [OpenAI Responses API + gpt-5-codex]
         -> math_renderer.render_math()
           -> Deepgram Aura TTS (REST, linear16, 24kHz)
             -> Speaker

Features:
- Mode switching mid-conversation via voice
- Shows interim transcript while student speaks (overwritten on completion)
- Shows agent response text before speaking it
- Graceful error handling on TTS and agent failures
- Clean startup, Ctrl+C exits
