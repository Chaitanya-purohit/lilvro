## 2. Description of Service

lilvro is a voice-only STEM learning companion. It operates as follows:

- The Student speaks into a microphone.
- Speech is transcribed locally using on-device models (faster-whisper).
- The transcript is sent to a third-party language model (OpenRouter) to generate an educational response.
- The response is converted to speech via Deepgram's text-to-speech API and played aloud.

There is no screen, no visual interface, and no persistent user account required to use the core service.
